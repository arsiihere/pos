**No gap (already available):** live ETA before Send (`eta-preview`), the wait on every tile (`stations-live`), option quantities (`SubmitOrder.lines[].options[].quantity` and `max_quantity`), add items to a token (`adds_to_order_id`), give ready items now (`MarkServed` with ids), remove / void (`RemoveItems` / `VoidItems`), pay a takeaway before it's served (05 B16), ready alert to the placer (03b `ready_to_serve`).

**Root cause to check first:** "Times will be set when sent" on the Gulberg kiosk is most likely `eta-preview` refusing with `BUSINESS_DAY_NOT_OPEN` (no open day). The design shows the reason ("Times show after Start day") and blocks before the first item (DayNotStarted).
