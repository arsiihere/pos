**Who and where:** the owner runs these on the pilot hardware (hub mini PC, Android tablet in the browser, Windows cashier kiosk in Chrome / Edge kiosk mode, an Android phone). **Never in a cloud session or CI** (CLAUDE.md "Cloud sessions and CI"). Power-loss checks stay with 03a task 28 style checks, not here.

**When:** after `module-02a-client` and `module-02b-client` are both on `main` (Z3), on one build of `main`. Write the date, the `main` SHA and pass / fail per row; a fail becomes a normal lane PR (or an owner question when the spec is silent).
