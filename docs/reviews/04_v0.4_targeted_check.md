## Checked and OK

- **H3-1 per action, row by row:** `void_requested` / `comp_requested` actor = `AlertRaised.requester_staff_id` (= envelope actor at raise); `void_answered` / `comp_answered` / `request_answered` actor = requester from `audit_requests` (folded from the earlier `AlertRaised`), approver = `RequestAnswered.answerer_staff_id`, method from the payload; `request_withdrawn` actor = requester; `request_pin_failed` actor = `answerer_staff_id` (field exists, strict schema), approver `NULL`; `item_voided` / `line_comped` from payload; every other action envelope actor, approver `NULL`. A reject has an approver (the rejecter) and the requester as actor — both filters find it, once each.
- **H3-1 vs `in_person`:** envelope actor = the requester-device session; the payload / `audit_requests` rule never uses it for actor or approver, so `in_person` rows are right; `detail_json.envelope_actor_id` keeps the device-session fact.
- **H3-2 implementability:** `stockEffects`' array loop (`stock.ts:546–553`) sees every cause up front, so the excluded set is a pure pre-pass; `effectsOf` gains one optional parameter threaded to `waitingReserve`; no event field, no 03a fold change; AddPrecookedStock / single-draft callers unchanged (empty set).
- **H3-2 within one entry:** per-entry order "moves, then the entry's `ItemVoided`s" (:108) puts every same-entry ended line after the move, so OQ-C parts (10c) and the moved line's own void are excluded; the approval path (one entry per request) is fully covered.
- **H3-3 OQ-F:** stored-`null` part started meanwhile → `wastage`, consumed at Start (P-5), releases nothing; still at `added` → `null` + `StockReleased{voided}`; header untouched in both.
- **H3-4 Void all:** parents-only + groups from V1 means a child in the void group is never also in `RemoveItems`; if the second command fails, the first is already committed and the sheet reloads (H3-14).
- **H3-5 codes:** `LINE_ALREADY_SETTLED` after a void, `VOID_PENDING` while pending — distinct states, no 02b code changes.
- **No other v0.4 regression found** in V1, V8, §3.4, §3.5, B-1, H-1, D-2/D-3, Q-3/Q-4, §9, tests 20–31; owner rulings OQ-A–OQ-F and K-1–K-8 are applied as ruled and not re-opened.
