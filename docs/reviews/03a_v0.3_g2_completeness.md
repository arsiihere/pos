## 4. The seven asked checks

1. **Contracts.** Every §4.2 event has a writer, a stream, a schema folder (`@pos/events/src/events/{order,station,stock}/`, task 1) and a reader (the reducer; 03b / 07 for `FireDispatched`, `SlipWarned`). Every §6.1 function has typed inputs except `capacityForLanes` (finding 9). Carried rows name a module and are buildable, except the missing `devices.point_id` and lane binding (finding 1).
2. **§4.5 coverage.** Missing: the 00 `devices.point_id` (finding 1, as asked: there is neither a 00 row nor a carried row), the 01b sync bound (2), `BootContext.clock` (6), the 01a `StockAdded` amendment (7). Everything else that overrides foundation / 00 / 01a / 01b / 01c / 01d has a row.
3. **Replay determinism and D44.** No clock and no `branchConfig()` inside `applyEvent` (times are `recorded_at`; config is `state.config` from `EngineConfigApplied`; return cook time and `max_carry_ms` are copied). Breaks: the exit window (finding 3) and the checkpoint (finding 5). Events not written by the tick (`FireDispatched { pulled }`, late-start `ReservationsShifted`) are named in §4.2 but not in the F rows (16).
4. **Statement and performance bounds.** `fires` 0 reads and no transaction idle (v0.2.1 frames from `due`); `fires_alerts` 2 + ≤ 1 + 01d's `raiseMany` / `closeMany` bounds, consistent with 01d's fixed-count rules — except that it is due on every pass while a raised condition persists (finding 4). Boot: step 2 = 2, step 3 = 4 + 2; crash restart ≤ 2 s; checkpoint replay ≤ 45 s inside 90 s (index build in finding 26). Sync bound arithmetic wrong (finding 2).
5. **Tests.** Gaps in finding 13; stale tests 8–10; E4 AC1–AC7 (ETA, hold-and-fire, slip) are all mapped, with AC6 and slip AC5 correctly out of scope; carried-row items map to tests 19, 39, 40, 43, 44, 55, 58, 85 (01a `StockAdded` row: finding 7).
6. **Size and build order.** 21 items, 28 tasks (~50 plan tasks); every task cites sections and files; tasks 1–18 independent, simulator gate before host tasks.
7. **YAGNI.** Findings 21 (`unit_changed` unreachable), 27 (`table_lock_ttl_ms` placement). Three policies, alternates, reserve units, checkpoint, two ticks and station-plan frames all trace to D3, D8, D26, pre-G2 #1, #12. Nothing found without a decision or story.
