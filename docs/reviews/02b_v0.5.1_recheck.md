- **O-1 (N-2):** "the dish is ordered again as a new round" (S:155) bills the guest a second time unless it is comped. §8's Return sheet should say so, e.g. offer "Order again" with the comp chips pre-opened, so a waiter does not charge a guest for a dish the kitchen spoiled twice.
- **O-2 (N-1):** a gap stamps "the device's most recent ended session" even when the device has an **active** session (Bilal logged in, his tablet drops 3 min): the stamp lands on Ali's old session, which the later-session rule already kills. Harmless, one wasted write per return; "only when the device has no active session" would skip it.
- **O-3 (N-2):** `OrderKitchenCleared` is now appended on almost every remove or void of an order that has any served line, also when `served_any` is already 1. Harmless for 02a; the event log gets a little noise.
