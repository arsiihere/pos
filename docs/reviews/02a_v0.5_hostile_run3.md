## 5. Verdict

**FIX.** 0 blockers, 4 majors, 10 minors (down from 7 / 13, and from 16 / 17 in run 1).

The four majors are each a one-paragraph fix:
- **1 (code mismatch):** `TableLockReleased` gets `alert_id`, so the handover `apply` passes `checkAlertIds`.
- **2 (T20 undone):** a non-holder's submit never takes a free lock; §8 offers "Keep as draft".
- **3 (R23 bypass):** absorbing checks the destination seating's assignee like a move.
- **4 (contract):** the fold reads `table_key` (= `seating_id`) for `dine_in`, not a field 03a's schema does not have.

This was the last full run. Fix the four majors and the minors in v0.6, then a **targeted check** of findings 1–4 only (the 03a v0.6.2 pattern), not a fourth hostile run. If that check passes, 02a v0.6 can go to the owner with OQ4 and the §4.5 rows for approval.
