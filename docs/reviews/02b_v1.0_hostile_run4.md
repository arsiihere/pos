## Verdict: **FIX**

One BLOCKER, six MAJOR, ten MINOR. Every fix is a sentence, a list entry or a test line inside 02b or an existing §4.5 row: B-1 adds one header to 00 §7.5's allowed list through the H-1 row; M-2 adds one in-memory field (`paused_since`) inside the owner's simplified rule without changing it; M-1 adds a refusal using an existing code; M-4 removes an error code; no new table, event type or engine change is needed. The spec is otherwise sound — the ledger, the engine contract and the lock/queue mechanics hold against the dependency specs and the as-built engine. The blocker is serious in effect but trivial to fix: without `X-Queued-At` in the CORS preflight list, the offline queue — the E5 promise the owner simplified H-1 around — never replays from the Android tablets. Apply B-1 and M-1–M-6 (and the minors in the same pass), then a targeted check of that diff only; no further hostile run is needed.
